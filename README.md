## 🧩 Tech Stack Overview  

### HTML  
HTML (HyperText Markup Language) is the **foundation** of the web. It defines the content and structure of web pages — headings, paragraphs, links, lists, forms, media.  
This repo’s `01_HTML/` folder contains beginners’ examples and senior-friendly revision files.

### CSS  
CSS (Cascading Style Sheets) is what gives your web pages **style and polish** — from colors, fonts, layouts, and animations to full responsive design.  
In `02_CSS/` you’ll find styling examples that transform plain HTML into beautiful surfaces.

### Bootstrap  
Bootstrap is a powerful front-end framework that speeds up UI building and ensures consistent, responsive design.  
You’ll find the `03_Bootstrap Framework/` folder full of ready-to-use components and layout demos — great for beginners fast-tracking and seniors reviewing modern workflows.

### JavaScript  
JavaScript is the **brain** of the webpage — logic, interaction, events, and dynamic behaviour.  
In the `04_JavaScript/` folder you have curated examples of DOM manipulation, event handling, mini-projects — perfect for exam prep, interviews, or teaching.
